# Browser image-to-video

Use the user's existing authenticated browser session via available browser/computer-use tools. Inspect the actual UI before selecting a model. Never assume published prices or allowances match this account. Keep a record of the visible generation settings and credits before submission.

1. Open the provider's image-to-video mode. Verify that the selected mode accepts a **start image**, rather than using the image only as style inspiration. Upload the intended file and verify its preview. If a crop is required, inspect what will be lost; make an approved copy rather than changing the original.
2. Select aspect ratio, duration, resolution, output count, audio, and model from the current controls. Check the displayed cost and remaining included allowance. Use one output for a draft unless alternatives are specifically useful.
3. Enter a motion prompt that describes action over time, camera movement, and fixed identity/product features. Avoid restating incompatible details from the still. Submit once and wait for completion.
4. Open and play the result, then download the MP4 or available video export. Record the local path and project link. If download is blocked, report the result link and the access limit.

## Google Flow specifics

In the current Flow UI, select **Video → Frames** and put the still in **Add start frame**. An optional end frame controls a transition to a different state. Use **Video → Ingredients** for extra character/object/style references, naming each reference's role in the prompt. Confirm model, aspect, length, output count, and credit cost shown in the account before Generate. Some models do not support every frame/ingredient combination; rely on the current UI and [Google's Flow help](https://support.google.com/flow/answer/16353334?hl=en) when controls differ.

For Grok, Higgsfield, Midjourney, Gemini outside Flow, and other UIs, inspect their current image-animation workflow rather than borrowing Flow control names. If a browser automation tool cannot upload or download reliably, use another authorized computer-use surface or report the specific blocker; do not claim the clip was produced.
