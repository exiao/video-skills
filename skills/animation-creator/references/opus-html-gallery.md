## How to recreate one

1. Choose an example by mechanism below. Open the live page and exercise its controls. Read its prompt, then inspect the corresponding HTML for the actual renderer, state model, and timing. The prompt describes intent; the code and playback show what was built.
2. Write a new brief with **subject, mechanism, composition, interaction, duration or loop, and output format**. Preserve only the chosen mechanism unless the original appearance is also requested.
3. Build a smallest viable scene and render a short motion sample. Check playback before layering in texture, sound, and controls.
4. For video export, give the animation a seekable frame clock or resettable fixed-step simulation; capture exact frames and inspect the encoded video. The gallery pages are interactive browser experiences and are not automatically deterministic video renderers. See [workflow.md](workflow.md).

A useful Claude brief: “Recreate the *mechanism* of example 054 (glyph pixels connected to springs) for the word [your word], in [your art direction]. Use [Canvas/SVG], support pointer interaction, expose a deterministic `renderFrame(frame)` for a [duration/FPS] export, and inspect the playback. Use the original page and prompt as references; make the design original.”
