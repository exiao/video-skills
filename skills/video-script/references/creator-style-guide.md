# Creator style guide from past videos

Use when scripting for a creator who has a back catalog. General hook advice describes other people. This guide describes how this creator actually talks.

## Build it

1. **Collect the catalog.** Use local copies of the creator's published videos. If the platform blocks bulk download, ask the creator to save them to a folder first. Note each video's views and date when available.
2. **Transcribe.** Local Whisper with word timing.
3. **Extract patterns, with examples.** For each item quote two or three real lines and their timestamps:
   - How openings are phrased and how long before the first point.
   - Pauses, laughs or beats the creator uses on purpose, with their position.
   - Sentence length, recurring phrases, words they never use.
   - How videos end.
4. **Compare top and bottom performers** when view counts exist. Mark differences as observations from this catalog, not proven causes.
5. **Save it** as `style-guide.md` in the creator's project folder. Keep it short and update it when the creator corrects a script.

## Use it

Read the style guide before writing a script for that creator. Match their phrasing and timing over generic patterns in [short-form hooks](short-form-hooks.md). When the creator rejects a line, record the reason in the style guide so the fix applies to every later script.

Source: How I AI, "Claude Code for creators: AI editing is here" (2026-10-19), Brooke Lacey's workflow.
